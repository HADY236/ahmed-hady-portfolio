# Ahmed Hady Portfolio

A bilingual (English/Arabic), responsive portfolio website built with HTML, CSS, and vanilla JavaScript. No paid services or build tools are required.

## Before publishing

1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your professional email in both the visible text and `mailto:` link.
3. Replace the sample GitHub and LinkedIn links with your real profile URLs.
4. Review the project descriptions and technology tags. Keep only skills you can discuss in an interview.
5. If you have project repositories or screenshots, add them to the relevant project cards.
6. Search for `https://github.com/` and `https://www.linkedin.com/` to find the sample links that need replacing.

## Publish for free with GitHub Pages

1. Create or sign in to a GitHub account at https://github.com/
2. Create a new public repository named `ahmed-hady-portfolio` (or another name).
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish. Your address will look like `https://YOUR-USERNAME.github.io/ahmed-hady-portfolio/`.

GitHub Pages supports static sites. This project does not need a backend or database.

## Help Google find the site

1. Open Google Search Console: https://search.google.com/search-console/
2. Add the exact published website URL as a URL-prefix property.
3. Complete the verification method Google provides.
4. Use URL Inspection to request indexing for the homepage.
5. Keep your name, role, project descriptions, and links accurate and consistent.
6. Add your published URL to your LinkedIn and GitHub profiles.
7. Indexing is not instant and cannot be guaranteed.
